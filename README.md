# FibToMe-privacy-policy

Privacy Policy, Terms of Service and Support pages for **FibToMe** (iOS, bundle `com.zani.fibtome`).

Published with GitHub Pages from the `main` branch, root folder:

| Page | URL |
|---|---|
| Privacy Policy | https://eresonance-zani.github.io/FibToMe-privacy-policy/ |
| Terms of Service | https://eresonance-zani.github.io/FibToMe-privacy-policy/terms.html |
| Support | https://eresonance-zani.github.io/FibToMe-privacy-policy/support.html |

These exact URLs are referenced from `Config.Privacy` in the app and are submitted
to App Store Connect. Changing a filename breaks the in-app links — update both.

Kept in a separate public repository (same pattern as `skulptAI-privacy-policy`)
so the app source can stay private while these pages remain publicly reachable,
which App Review requires.

No trackers, no external requests, no CDN — the pages are self-contained.
